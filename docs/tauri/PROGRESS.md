### M1 review fixes (2026-11-07, branch `tauri-pkg-M1-fixes`, on top of `tauri-pkg-M1`)

`tauri-pkg-M1` is checked out in the M1 worktree, so the fixes are one commit on `tauri-pkg-M1-fixes` (fast-forward of `tauri-pkg-M1`); merge that branch.

1. major, closed sessions kept answering: a DELETE, the 4-per-token trim or a revoke now ends the session's open SSE streams (`SseBody` watches the session's CancellationToken; the dispatch task, progress and elicitation senders queue nothing once the session is closed), so no `cancelled` / `Agent connection has expired.` answer follows the close, as with 1.1.4's transport.close().
2. major, initialization check: `jsonrpc::is_initialize` is the SDK's isInitializeRequest (the whole InitializeRequestSchema: protocolVersion string, ClientCapabilitiesSchema, ImplementationSchema; no id needed). A new-session POST without a valid initialize answers 400 -32000 `Bad Request: Server not initialized` and creates no session; an invalid initialize no longer skips the Mcp-Protocol-Version check; the closed-session 404 comes before the initialization checks (SDK order).
3. minor, zod checks: `schema_issues` covers `initialize` (zod 4 issue list in schema key order, incl. the intersection double issues of `elicitation` / `form`, AssertObjectSchema `custom` issues, icon `invalid_value`) and `tools/list` (`cursor`), so both answer -32603 and a bad tools/list no longer marks the cell connected.
4. minor, `notifications/cancelled`: dropped unless its params pass CancelledNotificationParamsSchema (`reason` a string when present, so `"reason": null` no longer cancels; `requestId` a RequestId).
5. minor, lone surrogates: ids are byte-identical now (`surrogate_ids.rs`: a string literal with an escaped lone surrogate travels as a marker; ids and a cancel's `requestId` keep it and are written back as JSON.stringify writes them, lowercase `\udxxx`). Deliberate deviation, kept: such strings elsewhere (tool arguments, names) still reach the tools as U+FFFD, since a Rust string cannot hold a lone surrogate.
6. major, `issue_token` race: the revoke and the new token happen under one lock (`revoke_locked`), `revoke_cell` removes every token of the cell; 500 rounds of two concurrent issues plus a revoke leave at most one token.
7. minor, panic hook: MCP request, session-call and task futures run marked (`unimux_mcp::in_request()`, a thread-local set per poll), and the app's hook returns early for them, so a request panic gives only the server's 300-char `MCP request failed` line and no `panic:` line or dialog (1.1.4 handle().catch).
