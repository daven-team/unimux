# unimux 1.2.1

- **The update from 1.1.x works when unimux was installed for all users.** 1.2.0 installed itself next to such an install, left the old version in place and the update window stopped at 99 percent. Now the update waits for the old version to close, removes it with its own uninstaller (Windows asks for administrator approval, as the updates of 1.1.x did) and points the Start menu entry, the desktop shortcut and a taskbar pin at the new version. Your data stays.
- If you already have 1.2.0 next to an older all-users install, updating to 1.2.1 cleans that up too.

Validated with the Rust and TypeScript test suites on Windows and macOS and a real update of an installed 1.1.4 on a clean Windows machine in four kinds of install: for the current user in the default folder and in a custom one, and for all users in Program Files and in a custom folder.
