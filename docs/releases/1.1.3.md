# unimux 1.1.3

- **A working mark that keeps turning.** The arc of an agent at work no longer slows down to choppy quarter steps after a few seconds: it turns evenly the whole time, capped at 60 frames a second, which on a fast 144 Hz screen costs less than half of an uncapped animation and no work on the page itself.
- **The same motion for every spinner.** The refresh arrow, the busy rings and the SSH connecting mark turn exactly like the working mark: one turn a second, at up to 60 frames, so nothing on screen turns faster or more smoothly than the rest.
- **No freezes when switching grids and projects.** The terminals of a grid get their graphics a few at a time instead of all in one frame, so the longest freeze when switching grid tabs or projects or detaching a grid dropped from 300-450 ms to about 80-110 ms in our measurements. Resizing the window or dragging the sidebar edge no longer stutters: the terminals reflow once the size settles.
- **Electron 45.** The app runs on Electron 45.2.2 (Chromium 156, Node 24), which also closes a security advisory of Electron 44.
- **Faster busy grids.** Terminals that print a lot move their scrollbar once a frame instead of on every line (86 % fewer timers and about 28 % less script time with 16 busy cells), and a new grid creates the graphics of all its terminals in one go, so a large grid is ready sooner.
- **Security updates.** Current versions of every package, with fixes for the advisories in zod, body-parser, undici, qs, fast-uri and ip-address.
- **The update window cleans up after itself.** The temporary copy it runs from is removed completely, without an empty folder left behind.

Validated with the full test suite, the CI build on Windows and macOS, and checks in the built app (terminals, MCP with the real Claude Code and Codex CLIs, databases, SFTP, detached windows, the update window, the installer and a start without a console), plus a new benchmark of startup, idle, busy grids and memory (`scripts/bench-perf.mjs`).
