# unimux 1.0.5

- **MySQL and MariaDB.** A new "MySQL / MariaDB" connection kind next to Postgres and Redis: SSH tunnel, TLS, the tree of databases, tables, views and routines, table data with paging, filters and staged edits, the SQL editor with several result sets, cancel, statement timeout, DDL and export. The server's flavour is detected when you connect and shown with its own logo.
- **Less memory per terminal.** On Windows all terminals now share one output thread in the terminal process instead of one each, and a closed or restarted cell no longer leaves its memory behind until the app quits. With 28 cells the terminal process uses about 50 MB instead of almost 300 MB.
- **Find in a file.** Ctrl+F in the editor opens a compact find box at the top right with a match counter, match case, whole word and regular expression toggles; Ctrl+H adds replace. Ctrl+F also searches the Markdown preview.
- **SSH cells in their own card.** Connecting, signing in, a failed or cancelled attempt and a dropped or ended session all show a card with the steps, how long they took and a log, with "Połącz ponownie" and "Zamknij komórkę". The terminal never shows the app's own status lines any more, and a new attempt starts with a clean screen.
- **Git history fills the panel** while the Changes section is collapsed.
- **SFTP selection in unimux's colours** instead of the bright system blue.
- A connection error in the database panel reads as one sentence.

Validated with the full test suite (new tests for MySQL against a fake server, the shared terminal output thread, the find box and the SSH card), real MySQL 8.4 and MariaDB 11.4 servers, and checks in the built app.
