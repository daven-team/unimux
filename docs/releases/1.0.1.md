# unimux 1.0.1

- **Faster typing over SSH.** The echo of a key no longer waits for an output timer. Each SSH terminal learns how long its server takes to answer a key, and opens the fast path for up to twice that time instead of a fixed 150 ms, which slow or distant servers often missed. Redraws right after an echo (zsh, fish, PSReadLine) and the echoes of fast typing take the fast path too, and a keystroke leaves as one write instead of three TCP segments. On a 200 ms server with Windows' default timers, the time our side adds to an echo went from 16 ms typical and 30 ms at worst to well under a millisecond, even with busy agents in the same grid.
- **SSH hosts like Termius.** Host cards are larger, with a colour tile and the user and tags under the name. A click selects a card, a double click or Enter connects, and the pencil opens the editor. The editor is grouped into Address (with the colour on the host's tile), General, port and Credentials, with the rest under "Show more". Passwords can be typed and saved right in the form.
- **SSH identities.** Save a user name with a password and/or a key once as an identity, and pick it under the user name field of any host. The host's credentials then show as one identity chip. Identity passwords live in the encrypted vault and are resolved in the main process at connect time.
- **Command autocomplete in SSH terminals.** While you type at the prompt, suggestions from the host's command history and your snippets appear under the cursor, with fish-style ghost text. ↓ enters the list, Enter inserts, → accepts the ghost text, Esc closes, and Tab and ↑ stay with the shell. Only echoed lines are remembered, so passwords typed at prompts never are. History is stored locally per host; switch the feature off or clear a host's history in Settings > SSH.
- **Colour themes for SSH terminals.** Seven themes, Unimux Dark, Midnight, Cyberpunk, Fjord, Lagoon, Nightshade and Daylight, shown as preview tiles in Settings > SSH, with a per-host override in the host editor. They apply live to open SSH cells; local terminals keep the app look.
- **Publish to GitHub.** A repository without a remote and with nothing to commit gets a "Publish to GitHub" button in place of Commit (also in the Git panel's "..." menu). Pick the name and private or public, and unimux creates the repository, adds it as origin and pushes the branch. Sign-in uses your GitHub CLI login; the token stays in the main process and reaches git only through the environment.
- **A Cursor-like Git panel.** It has a quiet commit message box and a steel-blue Commit button with a "Commit and push" menu. Change groups are collapsible rows with count pills, and their actions appear on hover. Hover highlights span the full row. An empty panel shows nothing instead of "no changes" and a zero. Fetch, pull, push and refresh moved into the History header, and the branch switcher into the Changes header.
- **Preview tabs.** A single click on a file opens it in one tab that the next file you click replaces, so browsing through files no longer fills the tab strip. A double click, an edit or a save keeps the tab. The tab is a normal editor from the start; its title is in italics until it is kept. New tabs open next to the active one.
- **Sharper Files tree.** File icons are new, crisp, colourful 16 px glyphs for over 50 file types instead of small letter badges. They also show in tabs and SFTP lists. The tree has 22 px rows with more room at the sides, thin outline folders with the git dot on their corner, and dimmed node_modules, out and release.
- **Lighter chrome.** Buttons are flatter with small corners, in the Cursor style. The side rail has thinner icons: Projects now uses a layers icon and Files the folder, and hovering only brightens the icon. The grid tab strip shows one clean project colour per tab instead of doubled, mismatched borders. The empty states of side panels (Databases, Projects, Snippets) now start with text right under the title, with links in the sentence and a full-width button.
- **SFTP polish.** The host picker is one compact list of host cards. Right-click menus only show what applies to the item, the empty space or the selection. Download sits in the menus instead of the toolbar. Selected rows are highlighted without a frame, and icons are thinner.

Validated with the full test suite (typecheck clean, 3152 tests) and a new SSH latency bench (`node scripts/ssh-latency-bench.mjs`) that measures keystroke-to-echo time through the Pty Host against a local SSH server with emulated round trips, busy agent terminals and Windows' coarse timers.
