# unimux 1.1.4

- **AI team workers start with their task again.** Recent Claude Code versions read every word after `--mcp-config` as one more config file, so a worker created by a coordinator (`create_grid`, a tracked task) took its own task for a file, stopped at once with "Invalid MCP configuration: MCP config file not found" and the task stayed queued. The task now goes first, before the options.
- **A worker whose first start failed still gets its task.** Started again (by opening its grid or "Uruchom ponownie"), a worker that never got going used to begin an empty conversation; it now starts with the task it was given.
- **The coordinator hears about a worker that stopped.** When a worker's CLI ends while its shell keeps running, the team counts the agent as exited, so a coordinator's `wait_for` reports it instead of waiting for the timeout.
- **Windows PowerShell by its full path.** Cells that use Windows PowerShell start it from its system folder, so they do not depend on the app's own PATH.

Validated with the full test suite, the real Claude Code 2.1.318 command-line parsing, and a new real-app check of a coordinator creating four workers in the background (`scripts/verify-team-start.mjs`, PowerShell and cmd).
