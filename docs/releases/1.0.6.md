# unimux 1.0.6

- **Tabs in their own window.** Drag a grid or a file tab out of the window, or choose "Przenieś do nowego okna", and it opens in a window of its own (for a second monitor) with only what it needs: its cells, "Dodaj", maximize and "Przypnij z powrotem". Terminals keep running, unsaved text moves along, closing the window puts the tab back, and detached windows come back where they were after a restart. Database, Redis and remote file tabs stay in the main window for now.
- **Server path completion in SSH.** After cd, ls, vim, nano and other commands, and for any path, Tab completes from what is really on the server (folders first, Tab and Shift+Tab cycle), listed over the cell's own connection.
- **SSH sessions after a restart.** Settings > SSH can reconnect the cells that were connected when the app closed, into the folder they were in. Off by default.
- **Find everywhere.** The find box now also works in diffs, CSV and Parquet tables, large files and terminals (Ctrl+Shift+F in a terminal, configurable). CSV tables now load up to 200 000 rows.
- **SQLite and SQL history.** A new SQLite connection kind (open or create a file, tree, table edits, SQL editor, DDL), a per-connection history of executed statements with search and favourites, and for MySQL triggers, events, every result set of a CALL and error positions in the editor.
- **Monitor.** A new panel in the side rail shows the CPU and memory of every cell's processes and of the app itself, and can end a process inside a cell.
- **Fewer processes per agent.** Claude Code 2.1.63 and newer report their status over HTTP instead of starting bash and curl for every tool call.
- **Notes and snippets with code.** Notes are edited with syntax highlighting and have a Markdown preview with copyable code blocks. Snippets can hold variables like {{name}} or {{name:default}}, asked for before pasting, plus {{project}}, {{path}}, {{branch}}, {{date}} and {{clipboard}}.
- **Terminals after a resize.** On Windows the line you type on is reflowed with the rest when a cell changes size, so a new command no longer lands in the middle of the old prompt, and a terminal moved to another window shows its history at the sizes it was written in.
- **Smaller fixes.** The built-in shell profile is named after the shell you chose (for example Command Prompt), the order of Notes and Snippets and the folded Changes section are remembered, selections use the app's steel blue everywhere, the split view can swap sides, and the update window shows the unimux logo again.

Validated with the full test suite (new tests for detached windows, server path completion, SQLite, the SQL history, the Monitor and snippet variables), real MySQL 8.4 and MariaDB 11.4 servers, a real Claude Code run for the HTTP hooks, and checks in the built app.
