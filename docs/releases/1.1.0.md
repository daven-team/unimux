# unimux 1.1.0

- **AI account limits that say the same thing in the same situation.** A card now has a few fixed looks: limits, "Sign-in expired" with one "Sign in again" button, or a short line when the limits are unavailable. Every expired sign-in looks the same, whether the renewal was rejected, Claude Code gave up on the main sign-in ("Login expired · Please run /login") or the account was switched out with cswap. An expired card shows no old numbers, and details are a tooltip instead of paragraphs.
- **A dead main sign-in is recognised.** When Claude Code clears a sign-in it can no longer renew, the main account's card says "Sign-in expired" right away instead of waiting for Claude Code to renew it.
- **Make another account main when the main sign-in is gone.** "Ustaw jako główne" works when the main sign-in expired, was cleared by Claude Code or is missing, so there is no need to switch with cswap. A sign-in that can still be renewed is saved first, as before.
- **No banner after a cswap switch.** Switching accounts outside the app no longer shows a warning banner; the card of the account that left shows "Sign-in expired" when its sign-in is dead, and a valid one looks like any other card.
- **A calmer taskbar.** The taskbar button no longer animates a progress bar while agents work, and the count of agents waiting for you is a red badge drawn with the system's own bold font, like chat apps have it.

Validated with the full test suite and checks in the built app (fake accounts with a dead main sign-in, a cleared and a missing sign-in file, a cswap switch, every card state, the taskbar badge at 100 to 200 % scaling).
