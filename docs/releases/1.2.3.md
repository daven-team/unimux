# unimux 1.2.3

A lighter and quieter unimux: less memory per agent, smoother grid switches and fewer wakeups while you are not doing anything.

1.2.2 was never published (a check of the macOS build stopped it), so these are the changes since 1.2.1.

- **On Windows an agent cell starts Claude or Codex directly, without a PowerShell running underneath it.** That is about 75 MB less per agent cell. Your shell still appears in the cell when the agent ends. Two differences: your PowerShell profile now loads after the agent ends instead of before it starts, and an agent installed with npm is started through its `.cmd` file.
- **Claude hooks use the fast http form again on every start.** A one-time fallback to command hooks no longer sticks, so a tool call no longer starts a few helper processes each time.
- **Hidden grids take less graphics memory.** A terminal out of sight for 5 minutes gives its graphics context back (the grid next to the shown one keeps its contexts). Grids not visited yet still get their contexts ready in the background, so a first visit stays smooth.
- **Switching to a grid that was not shown yet no longer stutters.** Its terminals are created one at a time, the focused one first.
- **Less work in the background:** hidden terminals no longer update their scrollbar while they print, the app stops checking timers that have nothing to do, the cursor stops blinking in a terminal left idle, the sound engine is closed after an alert, session titles no longer run git when nothing changed, and agents of the AI team waiting for a task are woken less often.

Measured on Windows with 60 terminals in three grids: an agent cell uses 9 MB instead of 84 MB (the agent itself not counted), the interface uses about 60 MB less with the window shown, idle CPU with the window shown is about half, the first terminal output after start comes about 180 ms sooner, and the first visit of a grid has no frames over 50 ms (before: up to 250 ms).

Validated with the Rust and TypeScript test suites on Windows and macOS and the real-app checks on Windows.
