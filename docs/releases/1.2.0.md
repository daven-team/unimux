# unimux 1.2.0

The whole application has been rewritten: the Electron and Node backend is gone, replaced by Tauri and Rust. It looks and works the same, keeps all your data, and updates from 1.1.x as usual.

- **A much smaller app.** The installer is about 16 MB instead of about 119 MB, because the app now uses the WebView2 runtime that ships with Windows instead of bundling its own browser.
- **Lower memory.** An idle 2x2 grid uses about 18 percent less working set and about 30 percent less private memory than 1.1.4.
- **Faster start.** The first terminal prompt appears about 40 percent sooner (1.1 s instead of 1.8 s), and the window shows in about half the time.
- **Smooth with many windows.** Restoring a minimized window with 20 busy terminals no longer stutters, and first visits to large grids are as fast as before or faster.
- **Your data stays.** Projects, grids, accounts, encrypted secrets, connections and drafts are read from the same folder, and 1.1.4 can still read them if you go back. Do not run 1.1.4 and 1.2.0 on the same data at the same time.
- **Closing a cell works as before.** It ends the terminal and the programs running in it; a program you opened in its own window, such as `code .`, stays open.
- **Safer root file operations over SFTP.** Under sudo, unimux refuses to delete or change files through a folder that another user could swap out from under it.
- **macOS: one Keychain prompt.** The new app is a new program to macOS, so the Keychain may ask once for access to the saved secrets. Choose "Always Allow".
- **macOS: a first-run caveat.** This release was built and tested automatically on macOS, but not by hand on a Mac. If something does not work there, please report it; the previous version keeps reading your data.

Validated with the Rust and TypeScript test suites on Windows and macOS (three macOS-only cases that depend on Windows-recorded references or on an open question about paused terminals are not run there), real-app checks on Windows against the shipped code path, the SSH and database server matrices in Docker, and a real update of an installed 1.1.4 to 1.2.0 on a clean Windows machine, in the default folder and in a custom one.
