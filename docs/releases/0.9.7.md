# unimux 0.9.7

- **Git panel no longer overlaps itself.** In a short side panel (a smaller window, or the AI limits open below) the history used to keep the height you dragged it to and slid over the commit message box and its search field. Now the commit box and at least two rows of changes always stay visible, a long list of changes scrolls, and the history gives way only when there is no room; in a tall window it keeps the height you chose.
- **Closing a worktree cell never loses work silently.** Before removing a worktree, unimux checks it and shows how many files are not committed and how many commits would be lost (also commits made on a detached HEAD). If there is anything, a second red confirmation names it. If the agent adds more work while you decide, the removal stops and asks again with the new numbers. A worktree that is clean is removed without force. A branch is deleted only if unimux created it for the cell; worktrees opened from History keep their branch.
- **Open files follow changes on disk.** A file open in the editor without unsaved edits reloads when an agent changes it, keeping your cursor and scroll position. If you have unsaved edits, a notice says the file changed, and saving offers Reload from disk, Show differences or Overwrite, instead of only "Try again".
- **History shows worktree conversations.** Conversations of worktree cells are listed too, labelled with their worktree, also after the worktree was removed. Resuming one into a folder that no longer exists says so.
- **Files and Git refresh after an agent's turn.** When an agent finishes a turn, the Files tree and the Git changes of its project refresh by themselves (once for several agents finishing together), so you see what it changed without pressing refresh.
- **Notifications name the agent.** A notification says which cell finished or needs you (its name, conversation title or profile) and in which project and tab, instead of "Claude Code finished" with a slot number. Several agents finishing at once become one notification that lists them.
- **Closing asks while agents are working.** Closing a grid, a cell, a project or the app while a Claude or Codex agent is in the middle of a turn asks first and names the agents. "Do not ask again" turns it off (and Settings turns it back on). A Windows shutdown or sign-out and update installs are never held by the question, and an unanswered question never keeps the app open for more than two minutes.
- **Visual fixes.** The "Drop to paste" overlay of a snippet dragged onto a cell is translated and lines up with the cell header. The AI team panel can be resized by dragging its top edge (or with the arrow keys) and keeps its height, which shrinks with the window. Long errors and hints in small cells scroll and keep their buttons in view. The sign-in terminal fits short windows, and the AI limits panel no longer squeezes the Files and Git panels.

Validated with the full test suite on Windows and macOS, the no-console start check, and real-app checks on scratch data for the Git panel layout (short and tall panels, long lists of changes), the window layout fixes, worktree removal (uncommitted files, unmerged and detached commits, work added during the confirmation), files changed on disk, closing with working agents (minimized window, repeated close, do not ask again), notifications and the refresh after a turn.
