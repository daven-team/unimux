# unimux 1.0.2

- **Testing a database connection uses the form's password.** "Testuj połączenie" with a wrong password now ends with "wrong user or password" right in the form, so you fix the password field and test again. It no longer asks for another password below the form. A login question that does appear inside the form (an empty password field, an SSH tunnel login) no longer saves the connection and closes the dialog when you answer it.
- **The colour palette stays inside its dialog.** A colour swatch near the right edge, like the one in the database connection form, opens its palette leftwards instead of pushing the dialog to scroll sideways.
- **Taller buttons.** Text buttons are 26 px tall again, so labels like "Nowy host" or the full-width buttons of empty panels no longer look squeezed. Icon-only buttons keep their compact size.

Validated with the full test suite, including the database connection tests over the real wire protocol, directly and through an SSH tunnel.
