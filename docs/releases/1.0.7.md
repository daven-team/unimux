# unimux 1.0.7

- **Cells as cards.** Every cell in a grid is a rounded card with a small gap around it: a header with the agent's icon and status dot, the name, muted details (profile, model, worktree branch, user@host) and compact actions, the terminal inside with some room around it, and the focused card marked with a steel-blue ring. Narrow cards hide details before they cut them, and a column can no longer be dragged narrower than a usable card.
- **Status bar under SSH terminals.** A slim bar under every connected SSH terminal shows the server's system and name, CPU with a small graph, memory, network, the logged-in user and the root disk (amber over 80 %, red over 90 %). Hover the disk for all filesystems, the user for everyone logged in, the CPU for load and uptime; right-click to hide it in one cell or everywhere. It is read over the cell's own connection every 3 s, only while it is on screen.
- **More precise statuses.** A permission question shows "needs you" at once instead of after 6 seconds, questions and elicitations too, and each status carries a short reason ("czeka na zgodę: Bash", "praca: Edit", "kod wyjścia 3"). Shell cells know when a command is running and how it ended, a CLI that quit or crashed is noticed, and a non-zero exit code is red everywhere.
- **Nicer notes.** Pinned notes, #tags with filters, checklists you tick in the preview with progress on the card, templates (daily note, meeting, checklist), sorting, a note as a full tab, quick capture of a terminal selection (Ctrl+Shift+L), pasted images, and .md import and export.
- **MCP.** Agents can ask you for a decision through MCP elicitations, waiting for another agent can run as a long task, agents can be named by their name instead of an id, and status hooks fall back to commands when http hooks are blocked or an older Claude Code runs in the cell.
- **A tidier app.** One spacing and colour scale with a single steel-blue focus ring, a title bar in three groups, Settings in six sections with a search, icons in every menu, a stricter command palette and clearer tooltips.
- **Fixes.** Running cells keep the name of the shell they were started with when the shell setting changes, a cell moved to its own window knows at once whether a command runs, and after a resize the cursor stays at the end of a Windows prompt.

Validated with the full test suite, a real Claude Code and Codex against the MCP server, real Debian and Alpine servers for the SSH status bar, and checks in the built app.
