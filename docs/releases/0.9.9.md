# unimux 0.9.9

- **Faster typing in terminals.** A typed key's echo now reaches the screen in about 2 ms instead of about 16 ms: on Windows the terminal process waited for the next timer tick before sending the echo. SSH sessions also send every key at once instead of waiting for the previous one to be acknowledged (like OpenSSH's own client), which matters most on slow or distant connections.
- **Move files in SFTP.** Drag files and folders onto another folder on the same side, onto a folder in the path bar or onto "..", or use Cut and Paste (Ctrl+X, Ctrl+V). Moves on the server use rename; moves on your computer across drives copy first, check every file and only then remove the original. A folder cannot be moved into itself, and existing names ask the usual Replace, Skip or Keep both.
- **Edit server files in tabs.** Double-click a file in SFTP (or choose Open) to open it in an editor tab at the top, marked with its host. Save with Ctrl+S and it goes back to the server: written under a temporary name readable only by you and renamed into place, keeping the file's permissions. If the file changed on the server meanwhile, you choose Reload, Show differences or Overwrite. Images open as a preview; binary and very large files offer a download. Files from the local side open the same way.
- **Permissions.** "Uprawnienia…" in SFTP sets permissions with digits (644, 0755) or checkboxes for owner, group and others, with setuid, setgid and sticky. For folders it can apply to everything inside, with separate values for folders and files, and shows how many items change first.
- **SFTP as root.** A host can run SFTP through sudo ("Uruchamiaj SFTP przez sudo"), with or without a sudo password; unimux asks for the password in the SFTP view when sudo needs it, also on servers with Polish or other languages, and never sends it before sudo asks. A badge shows when SFTP runs through sudo. Editor tabs never save through the sudo session.
- **Refresh shows it is working.** The refresh button turns while a folder is read, and the old list stays in place instead of flashing empty.
- **Colour picker.** The colour palette in the SSH host editor and in Settings no longer cuts off its last column, and the custom colour row stays on one line.

Validated with the full test suite on Windows and macOS, a new typing latency check (SSH echo median about 2 ms, fails above 8 ms), the perf check, and real-app checks against a local SSH test server: moving by drag, path bar and Cut/Paste, permissions with digits, checkboxes and recursive masks, sudo with and without a password on a Polish-language server, editing and saving server files with conflicts, images, large files and reconnects, plus all earlier SSH, SFTP, Git, layout, worktree and close checks.
