# unimux 1.0.3

- **Redis in the database tree, like DataGrip.** A Redis connection unfolds like a Postgres one: its DBs (db0 to db15, or as many as the server has) with their key counts, and under a DB its keys as a tree grouped by ":", loaded page by page with "Wczytaj więcej". Double-click a key to open it in the key browser of its DB with its value. A login the tree needs is asked right in the panel.
- **Colours belong to folders.** Right-click a connection folder in "Bazy danych" to give it a colour; its connections show it in their tabs. The connection form has no colour of its own any more, and folders start with the colour their connections had.
- **Postgres and Redis icons.** Connection rows and database tabs show the Postgres elephant and the Redis stack instead of "PG" and "RD" badges.
- **A connection form that fits.** The new or edited connection opens in a wider, DataGrip-like dialog: labels on the left, and the details on General, SSH and TLS, and Advanced pages, so nothing has to be scrolled.
- **Cleaner Redis view switcher.** The view in front (key browser, console, Pub/Sub, server) is marked with a lighter background instead of a coloured line under a rounded button.

Validated with the full test suite, including new tests for the Redis tree and folder colours.
