# unimux 1.0.4

- **Notes.** A Notes panel next to Snippets (button in the title bar, Ctrl+Shift+O): notes for every project or for one, edited right in the panel and saved as you type. With Notes and Snippets both open the right column splits in half, the one opened first on top; close one and the other fills the column.
- **A file beside the grid.** "Otwórz obok gridu" (tab menu, the editor header, the Files and Git panel menus) shows a file, a diff, a table or a Redis view next to the grid instead of over it, with a divider you can drag.
- **Clone in the Git panel.** A project without a repository offers "Sklonuj repozytorium tutaj" next to "Utwórz repozytorium", and the "..." menu has "Klonuj repozytorium..." that clones into a new folder and adds it as a project. GitHub sign-in is used for github.com addresses.
- **A calmer Git panel.** No worktree dropdown above the changes (the branch switcher is in the Changes header), no "trusted repository" banner, crisp Fetch, Pull and Push icons with one-word tooltips, and a plain empty state like the Snippets panel.
- **SSH connects behind a card.** While an SSH cell connects it shows the host, three steps (connecting, signing in, terminal) and a status line instead of raw terminal text, with the host key and password questions inside it, a log of what happened, and "Połącz ponownie" when it fails.
- **SSH without a pinned tab.** The SSH view opens from the side rail only and has no tab in the top strip any more; it stays open in the background with its sessions and SFTP connections.
- **Host colours everywhere.** SSH cells are drawn in their host's colour, and the "Dodaj" menus show the colours of hosts and profiles.
- **Tabs of one project.** Settings > "Karty na górnym pasku" (or the "Wszystkie karty" menu) can show only the active project's grids and files instead of all projects'.
- **Styled tooltips.** Every tooltip in the app is a dark bubble in the style of the menus instead of the plain system one.
- **Smooth spinners.** Refresh arrows and busy rings turn smoothly instead of flipping twice a second.
- **Marquee selection in SFTP.** Drag from an empty part of a file list to select files with a rectangle, like Explorer; Ctrl adds to the selection.
- **Real Postgres and Redis logos** in the database panel and tabs.

Validated with the full test suite, including new tests for notes, the split view, cloning, the strip scope, the SSH connecting card, tooltip placement and marquee selection, and with checks in the built app.
