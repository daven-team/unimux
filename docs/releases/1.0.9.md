# unimux 1.0.9

- **"Czeka na Ciebie".** A new side panel (the bell) lists every cell that needs you, in every grid and window: permission requests, questions, finished turns you have not read yet, errors and usage limits, longest waiting first. Click a row to jump to the cell; Ctrl+Alt+PageDown / PageUp go to the next or previous one from anywhere, also from a detached window.
- **A prompt queue for each agent.** Line up follow-up prompts for a Claude or Codex cell (Ctrl+Shift+D, the palette or the cell menu): the next one goes out when the agent finishes its turn, after a short countdown you can cancel. The queue pauses with the reason on a permission request, a question, an error, a usage limit or when you type in the terminal, and comes back paused after a restart.
- **Search every conversation.** Ctrl+Alt+F searches all Claude Code and Codex conversations in all projects, without caring about Polish letters, with filters for the agent, the project and the date and a preview of the conversation. Resume a result in a new cell or the focused one, or jump to the cell that already has it open.
- **Answer from the notification.** A permission notification has "Zezwól", "Odrzuć" and "Pokaż". The answer is typed only while that same dialog is still on screen; otherwise the button just shows the cell. It can be turned off in the alert settings.
- **The taskbar and the Dock.** The app's taskbar button shows how many agents wait for you and a progress bar while agents work, and the window flashes when an agent asks for you while you are elsewhere. On macOS the Dock icon gets the count.
- **"Renew in unimux" asks once.** An account you renewed in unimux stays the app's own however often you switch accounts. It asks again only when cswap really backed that account up in the meantime.
- **A clearer card header.** The working dot sends out visible ripples instead of a faint flicker, and the generic profile name ("Claude", "Codex") is gone next to the context usage: the agent's mark already says it.
- **Smaller fixes.** The History of the Git panel keeps the height you set when you open a commit, the "AI account limits" header stays pinned while you scroll the accounts, the window shows up about 0.6 s sooner at start, and a message delivered to a Codex cell no longer freezes the app for most of a second.

Validated with the full test suite and checks in the built app (scripted Claude cells with real hooks, a local mock of the Claude API for the prompt queue, generated conversations for the search, permission notifications and the taskbar state).
