# unimux 1.0.0

- **Grids of all projects side by side.** The tab strip at the top now shows the open grids and files of every project, not only the active one, so you can keep grids of different projects open as tabs and switch between them with a click or Ctrl+Tab. Each tab carries its project's colour (and its name when two grids share a name); clicking one switches the project with everything that follows it. Drag tabs to reorder them across projects; the order is kept after a restart. Closing a tab works as before, and the close shortcut closes only the tab in front.
- **Databases: Postgres and Redis.** A new "Bazy danych" panel in the side rail keeps your database connections: Postgres or Redis, host, port, user, password (stored encrypted, like SSH passwords), database, TLS (with clear labels when a mode does not verify the certificate) and "Połącz przez SSH" through one of your saved SSH hosts, so databases that listen only on your server's localhost work without opening ports. Test a connection before saving it; mark it read-only and table edits, data-changing statements and Redis writes are refused (the SQL editor and the Redis console offer an explicit one-time override that shows what will run). Nothing has to be downloaded: the drivers are built in.
- **Postgres.** Browse databases, schemas, tables, views, functions, columns, keys and indexes, and see a table's DDL. Open a table's data in a tab: paging, sorting, a WHERE filter, NULL shown distinctly, long and JSON values in a side viewer, copy and export to CSV or JSON. Edit rows in place: change cells, add, duplicate and delete rows; changes wait highlighted until you save them, "Pokaż SQL" shows exactly what will run, everything is saved in one transaction, and a row changed by someone else meanwhile stops the save and is marked. The SQL editor runs the statement under the cursor (Ctrl+Enter), the selection or the whole script, shows several result sets with timing, loads more rows on demand, cancels long queries, keeps a history (passwords masked) and offers explicit transactions that are always visible.
- **Redis.** Browse all keys with a pattern search (safe SCAN, never KEYS), a type filter and a ":"-tree, with type, TTL and size per key, across databases. View and edit every type: strings (with a JSON view and a hex view for binary data), hashes, lists, sets, sorted sets and streams; set or remove a TTL, rename, delete, and delete by pattern after counting what matches. A console with history and completion asks before dangerous commands such as FLUSHDB and never stores passwords; Pub/Sub subscribes to channels and patterns with live messages and lets you publish; a server tab shows INFO, the slow log and connected clients.
- **Quiet in the background.** Databases run in their own process, started only when you first connect, so a slow query never blocks terminals or the window.

Validated with the full test suite on Windows and macOS (Postgres tests over the real wire protocol with PGlite, a local Redis protocol server and the SSH test server for tunnels), and real-app checks: grid tabs across projects, Postgres connections direct and through SSH, the tree, table data with editing, conflicts and read-only connections, the SQL editor with multiple results, load more and cancel, Redis browsing, every value type, console, Pub/Sub and server info, plus all earlier SSH, SFTP, Git, layout, worktree and close checks.
