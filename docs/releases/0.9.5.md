# unimux 0.9.5

- **unimux starts again on Windows.** Since 0.9.3 the app closed itself about two seconds after starting when it was opened from the Start menu, the taskbar, a desktop shortcut or right after an update, because starting the terminal process failed without a console window. The terminal process now gets its own output channel, so the app starts however you open it. If 0.9.3 or 0.9.4 does not open for you, download and run the 0.9.5 installer from the release page once: your projects, grids and accounts are kept.

Validated with the full test suite, a reproduction of the crash on 0.9.4 (app started without a console, exit code 0x80000003) and the same start with the fix, including a copy of a real layout whose cells started and printed output.
