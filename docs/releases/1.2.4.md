# unimux 1.2.4

Project folders, a menu bar, files from Explorer opened in unimux, and terminals that stay smooth while a build is running.

- **Project folders.** Drag a project onto another one to put both in a folder, or create one with "New folder" (Ctrl+Shift+K). A folded folder shows the icons of its projects in a small grid and the summed status badges of everything inside; it remembers whether it is folded. Rename it with a double-click, delete it from its menu (its projects stay).
- **Open files from Explorer.** Right-click a file and choose "Open in unimux" (on Windows 11 under "Show more options"), pick unimux in "Open with", or make it the default app for a file type in Windows Settings. The file opens in the built-in editor, also when unimux is already running. On macOS unimux appears in Finder's "Open With" for text and code files.
- **A menu bar** next to the logo: File (new text file, open, save, save as, close, new project or folder, settings, quit), Edit (undo, redo, cut, copy, paste, select all, find, acting on the editor, a text field or the terminal you were in) and View (panels, command palette, zoom of the whole window, full screen, maximize the cell). The "unimux" text in the title bar is gone.
- **Untitled text files.** File > New text file (Ctrl+N) opens an empty tab; Save asks where to save it, and Save as (Ctrl+Shift+S) works for every file.
- **Jump to any agent.** The command palette (Ctrl+K) lists every Claude and Codex cell of every project by name and conversation title; Ctrl+1 to Ctrl+9 focus a cell of the current grid.
- **Turn timer.** A working agent shows how long it has been working ("working 3:12"), and the finished notification says how long the turn took.
- **Grid-wide actions** in the grid tab's menu and the palette: interrupt all working agents, restart and resume all agents, mute or unmute the alerts of all of them.
- **Smooth terminals under load.** unimux's window and its main process now run above normal priority, so a build that uses every core (in a cell or in another program) no longer makes typing, scrolling and drawing lag in every terminal. With 16 busy cores the slowest key echo went from about 110 ms to about 50 ms.
- **Terminals keep their width.** A terminal no longer changes its column count when its graphics context comes or goes, which made agents redraw at another width and left messages of two widths in the history.
- **A quieter scrollbar** in terminals: thin, shown only while the pointer is over the terminal.
- **Monitor panel:** each cell block and the app section fold to one line (one by one or all at once); the hover highlight of the app rows no longer spills over its neighbours.
- The installer and the uninstaller have the unimux icon.

Validated with the Rust and TypeScript test suites on Windows and macOS, the real-app checks on Windows and the installer checks on a clean Windows machine (the Explorer and Open with entries appear after install and are gone after uninstall).
