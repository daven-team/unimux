# unimux 1.0.8

- **Database, Redis and remote file tabs in their own window.** "Przenieś do nowego okna" and dragging a tab out now work for table, SQL and DDL tabs, Redis tabs and files open from SFTP too. Open transactions, staged edits, Redis subscriptions and unsaved remote text move along without a new login, and the tabs come back after a restart.
- **Context usage in the card header.** Claude and Codex cells show how full their conversation is ("Kontekst 32%") with a small bar, amber over 70 % and red over 90 %; hover for the tokens and the model. It is read from the conversation files when the agent reports, never by polling.
- **Type a path in SFTP.** Click the path bar (or Ctrl+L, F4, Alt+D) to type or paste a path, local or remote, with folder suggestions, Tab completion, a clear error for a path that does not exist, and "Kopiuj ścieżkę". A path to a file opens its folder with the file selected.
- **The real Claude and Codex marks.** The orange Claude spark and the Codex cloud with its prompt replace the hand-drawn icons everywhere.
- **A better SSH status bar.** It shows the machine's uptime, other logged-in sessions next to you ("root +2", you last in the list), upload and download separately, and lays out as one compact row that switches to shorter forms before anything is hidden.
- **Cleaner cards.** The frame of a coloured or focused card is one even ring at every Windows scaling, the status dot is no longer cut off, and a working cell's dot pulses smoothly.
- **Help in the right column.** The "?" of Notes opens fully inside the window, and Snippets have their own "?" again with what they are for and how to use variables.

Validated with the full test suite and checks in the built app (database tabs with SQLite, PGlite and a local Redis server, SFTP through a local SSH server, scaling at 100, 125 and 150 %).
