# unimux 0.9.6

- **SSH cells can reconnect when the app starts.** A saved SSH host has a new option, "Reconnect when the app starts" (off by default). After a restart or an update, the SSH cells of such hosts connect by themselves as soon as you see them; cells in tabs you have not opened yet connect when you open them. A host that asks for a password, a key passphrase or a new host key still asks in the cell. Reloading the window and a restart of the terminal process do not reconnect anything.
- **Reconnect all SSH.** The grid tab menu and the command palette get "Reconnect all SSH" when a grid has SSH cells that are not connected (never started, ended or failed). It connects exactly those and leaves connected cells alone.
- **Only the app window can change things.** Every request that writes files, changes the app state, starts or stops terminals, changes a git repository, opens files or programs, reads the clipboard or installs an update is now accepted only from the unimux window itself, like the account actions already were.
- **Quitting waits for an account switch.** Quitting right after "Set as main" or while an account switch is running now waits for it to finish (up to 5 seconds, and up to 3 more once the terminals are closed), so the Claude Code sign-in is not left half switched. No new account action starts once quitting began.
- **A start check for every release.** Every Windows build is now started once the way a shortcut or the installer starts it (no console), so a crash like the one in 0.9.3 and 0.9.4 stops the release before anyone gets it. Release builds also reuse the Electron downloads instead of fetching them again for every release.

Validated with the full test suite on Windows and macOS, the new start check (it fails on the 0.9.4 build with the same exit code as the crash and passes on 0.9.6), and the SSH real-app check against a local test server (option on and off, app restart, window reload, "Reconnect all SSH" from the tab menu and the palette).
