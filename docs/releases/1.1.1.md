# unimux 1.1.1

- **Limits right after a restart.** An expired sign-in stays "Sign-in expired" across a restart instead of showing old numbers as "data from ...", and every account is read right after the app starts, then on the interval.
- **A real refresh.** The refresh button of the AI account limits reads every account at once and spins until all answers are in; only a real rate limit from Anthropic makes it wait, and the card says until when.
- **Limit warnings.** A system notification when an account uses a set part of its 5-hour (default 80 %) or 7-day limit (default 90 %), once per account and period, with the time of the reset; each limit has its own switch and threshold, and an optional notice tells you when a limit is available again (Settings > Powiadomienia i dźwięki > Limity kont AI). While the warnings are on, the limits are also read when the window is minimized.
- **One prompt to several agents.** Ctrl+Shift+U (or the grid tab menu, or the palette) sends a prompt to the Claude and Codex cells you pick, in every grid and window. Idle agents get it at once; busy ones are skipped with the reason or, if you choose, get it in their prompt queue. A summary says how many got it.
- **Grid templates.** "Zapisz jako szablon…" in the grid tab menu saves the layout, sizes and cells (profile or SSH host, name, colour, role, model, worktree, muted, start folder). Open it in any project from the "Dodaj" menu, the palette or the grid dialog, where templates can also be renamed, updated or deleted. A cell can now start in a folder of the project.
- **Export a conversation to Markdown.** From a cell's menu, the palette or a conversation search result: a preview, optional one-line tool calls, then save to a file, copy, or keep as a note.
- **Ctrl+Tab goes to the tab you used last.** A tap switches between the last two tabs; hold Ctrl and press Tab again to walk further in a switcher, Ctrl+Shift+Tab goes back. The old next and previous tab in strip order can still be bound in the shortcut settings.

Validated with the full test suite and checks in the built app (a restart with saved limits, a slow limits server and the refresh button, limit notifications, a prompt to Claude and Codex cells including a detached window, a template opened in another project, Markdown exports of Claude and Codex conversations, the tab switcher with the focus in a terminal).
